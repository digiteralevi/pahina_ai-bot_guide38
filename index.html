Pahina AI — Setup Guide

Build your own AI sales agents, no tech skills needed

Just follow each step from top to bottom. You don't need to know how to code: everything you need to copy is on this page with a Copy button, and the final files download ready to use. Every service used here is free.

With one install you can create as many chatbots as you want: one for each business, product or client. Each bot gets its own link, products, payment details and personality.

Stuck on a step? Tap Ask Pahina AI at the bottom right. Our assistant will walk you through it.

What you need:
  • A laptop or computer (much easier than a phone)
  • A Gmail account
  • About 45 minutes, and a notepad to write down your password
Words you'll see (read this if you're new)
Supabase — a free "storage room" for your chatbot's info: products, prices and leads (customers who leave their contact details).
SQL Editor — the place in Supabase where you paste code to set up that storage. It's just copy and paste.
Edge Function — the chatbot's "brain", running on Supabase. Your AI key is kept here so nobody else can see it.
Gemini API key — like a password that gives access to Google's AI. It's free.
Netlify — a free place to put your chatbot online and get a link.
Bot link (?tid=...) — every bot has its own link ending in ?tid= plus a long ID. That's the link you share with that bot's customers.
Already installed an older version? Upgrade to multi-bot (read this first)

This is for you if your chatbot was working before My Bots existed. Your products, leads and settings will not be deleted: your current bot becomes your first bot (Default), and your old link keeps working. Follow the steps in order.

  1. Database: click this, then in Supabase → SQL Editor → New query → Ctrl+V → Run. You should see "Success. No rows returned". You don't need to enter your email again.
  2. Chat function: copy the new code:

    In Supabase → Edge Functions → click chat → Code tab. Click inside the editor, press Ctrl+A, then Ctrl+V, then Deploy.
  3. New files: go to Step 7, enter your Project URL and anon key again, and download the new index.html and setup.html.
  4. Replace the old files on your site. Netlify: open your site → Deploys → drag in the folder with the new files. Vercel/GitHub: upload both files to the same repo so they replace the old ones.

~5 minutes

Troubleshooting




The chatbot shows "Not connected yet"
The Project URL or anon key in your files is wrong. Go back to Step 7, download both files again, and upload them again as in Step 8.


"The AI is not set up yet. Please let the page owner know."
This bot has no Gemini key to use. Log in to the admin panel (your link + /index.html?admin=1) → Settings → Shared Gemini key → Save. Or add a key in that bot's Config only.


"The database is not upgraded yet" or "did you run the upgrade SQL?"
Your files are new but your database is still old. Do steps 1 and 2 of "Already installed an older version?" at the top.


"Sorry, the AI is not available right now"
  1. Make sure the function is named exactly chat in Step 5.
  2. Make sure the Gemini key is correct (no extra spaces).
  3. Your free key's limit may be used up; try again in a few minutes.
  4. In Supabase → Edge Functions → chat → Logs you can see the exact error.


All my links open the same bot
Check that the link ends with ?tid=. A link without ?tid= (or with a wrong ID) always opens the Default bot. Copy the right link from admin → My Bots → Copy chat link. You can change which bot is the default with Make default.


How do I share one bot's admin with my client?
  1. In Supabase → Authentication → Users → Add user → Create new user: enter your client's email and a password, and tick Auto Confirm User.
  2. In admin → My Bots → Share with client on that bot → enter the same email → Add client.
  3. Give your client that bot's Copy admin link and the password. They'll only see and edit that bot.

The bot gives wrong prices
Admin panel → choose the bot under Editing bot → Products → fix the price → Save products. The AI only answers from the products, payment, FAQs and description you entered.


There's no "Legacy API Keys" tab, only a "publishable key"
Use the publishable key (starts with sb_publishable_) in Step 7. Then in Supabase → Edge Functions → chat → Details or Settings, turn off Verify JWT (or "Enforce JWT verification") and save. The chat needs this to work with that kind of key.





Security and privacy notes




    

  1. The admin panel needs a login, and only you have an account because sign-ups are closed (Step 4). A client you give access to can only see the bot shared with them.
    2. 

  2. Your Gemini keys are kept in your Supabase and are never visible to visitors.
    3. 

  3. The chatbot collects customers' names, emails and phone numbers. In the Philippines this is covered by the Data Privacy Act, so only use the info to contact them, and add a simple privacy notice to your page.
    4. 

  4. AI can make mistakes. Set your products, prices and FAQs clearly, and check its answers from time to time.
